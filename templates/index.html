Active Security Controls Architecture

Every layer adheres to OWASP Application Security Verification Standards (ASVS).

Password Hashing

Argon2id Algorithm

Employs the winner of the Password Hashing Competition (PHC). Configured with 64 MB memory cost, 2 iterations, and 1 parallelism thread to resist GPU/ASIC brute-force cracking.

Data Layer

Parameterized Queries

Complete SQL injection mitigation via SQLite prepared statements. User inputs are treated strictly as literals, eliminating SQLi attack vectors.

Session Guard

Session Fixation Defense

Sessions are completely cleared and regenerated upon authentication. Cookies are bound with HttpOnly, SameSite=Lax, and 30-minute idle lifetimes.

Transport Guard

Flask-WTF CSRF Defense

Synchronizer token pattern verifies all state-changing POST requests. Cross-site request forgery attacks are caught and rejected with HTTP 400.

Anti-Brute Force

Rate Limiting & Lockout

Granular rate limiting via Flask-Limiter (8 attempts/min on login) paired with automatic 15-minute account lockout after 5 consecutive failed attempts.

Enumeration Defense

Timing-Safe Generic Errors

Dummy cryptographic hashes are verified on non-existent accounts to eliminate response-time discrepancies, preventing user account enumeration.
